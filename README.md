# Rushda Shahin – iPhone-style Portfolio

A portfolio that opens like a phone: lock screen, home screen and one app per section.

## Run it
Open `index.html` in any browser. No install or build step needed.
(The Inter font loads from Google Fonts, so use an internet connection for the best look.)

## Folder
- `index.html`  page structure (phone, lock screen, home screen)
- `css/style.css`  all styles and animations
- `js/main.js`  app content, animations, clock, typing effect

## Edit your details (in `js/main.js`)
- `DK`  dock icons and links (Hire me, Mail, LinkedIn, GitHub)
- `EX`  work experience
- `SK`  skills
- `CT`  GCC map pins
- `V`   the content of each app (About, Projects, Education, Locations, Certificates)

## Put it online (free)
- **Netlify:** drag the whole `rushda-portfolio` folder onto app.netlify.com/drop
- **GitHub Pages:** push the folder to a repo, then Settings > Pages > deploy from `main`
- **Vercel:** import the repo, no settings needed
